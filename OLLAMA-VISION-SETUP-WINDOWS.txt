V-TRADE AI — FINAL OLLAMA VISION SETUP

1. Install Ollama on Windows.
2. Run START-OLLAMA-VISION-BRIDGE.cmd.
   - It checks Ollama.
   - It pulls qwen2.5vl:3b if missing.
   - It starts the local bridge at http://127.0.0.1:11435.
3. Keep that CMD window open.
4. Open the V TRADE AI GitHub Pages dashboard.
5. Screenshot AI -> Choose File -> upload PNG/JPG/WebP (max 6 MB).
6. Click Analyze Screenshot.

WHY THE BRIDGE EXISTS
The browser must not call Ollama's 11434 API directly. Direct browser access can fail because of CORS.
The local bridge receives the image from the browser and calls Ollama server-side.
So the flow is:
GitHub Pages -> localhost:11435 bridge -> localhost:11434 Ollama -> Vision model.

RENDER NOTE
Render cannot reach Ollama running on your personal PC at 127.0.0.1.
Therefore the primary/local path is the PC bridge. The Render -> Ollama fallback only works if OLLAMA_BASE_URL on Render points to a reachable Ollama host.

VISION SAFETY
The Vision module is evidence extraction only. It returns WAIT as the final signal and does not create orders, Entry, SL or TP.
